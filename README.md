# Udemy Clone Website 🎓

This is a simple Udemy Clone website developed using **HTML and CSS**. The website is inspired by the Udemy online learning platform and includes a clean design, navigation bar, course sections, and attractive layouts.

### Features

- Simple and user-friendly interface
- Course listings with images
- Navigation menu
- Clean and attractive design

### Technologies Used

- HTML5
- CSS3

### About the Project

This project was created to practice my frontend development skills and improve my knowledge of HTML and CSS by building a simple website inspired by Udemy.# udemy-clone-simple-website
